# Security

Elite Editor is an early local, single-user application. Bind it to loopback and do not expose the Node API directly to the internet. It has no multi-tenant authentication or isolation.

Do not put API keys, personal recordings or private project files in public issues. For a suspected vulnerability, use GitHub's private vulnerability reporting option if enabled. If that option is unavailable, open an issue requesting a private contact channel without exploit details or sensitive data.

Optional providers receive the prompts/media explicitly sent to their APIs. Local analysis models and their runtime are separate installations. Keep your dependencies updated and back up browser project data before clearing storage.
